## Purpose

This baseline records Yamachat's proprietary licensing position, project
identity, principal branding provenance and third-party licensing boundary.

It is intended to create a durable, dated evidence trail. It is not a
government copyright registration, trademark registration, design registration
or court determination.

## Proprietary licensing position

From publication of this baseline forward, proprietary Yamachat material is
expressly distributed with all applicable rights reserved under the
`YAMACHAT PROPRIETARY LICENSE`.

Yamachat itself is not intended to be an ISC-licensed open-source project.

Third-party components remain governed by their own licences.

## Historical ISC package metadata

Earlier Yamachat desktop package metadata contained:

`"license": "ISC"`

The project owner records that this did not reflect his intended current
licensing model for Yamachat as a whole. The project metadata is therefore
changed prospectively to `UNLICENSED`.

This clarification does not purport to revoke any right that may already have
been validly and irrevocably granted to a third party in relation to an earlier
copy.

## Cross-platform distribution

The legal baseline is intended to accompany Yamachat across:

- Windows desktop;
- Web and PWA;
- Android; and
- iOS-derived mobile builds where distributed.

Build configuration should package or publish the legal documents without
changing Yamachat runtime behaviour or user-interface layout.
