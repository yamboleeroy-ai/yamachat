# Yamachat 1.0.106

- Dokončené **Podmínky používání** a **Ochrana osobních údajů** jsou zapojené do stávajícího právního UI místo placeholderů.
- Oba dokumenty jsou součástí distribučních balíčků pro **Windows, Web/PWA, Android a iOS/PWA**.
- Karta **Vývojář / Kontakt** je po odstranění věku znovu vyvážená; desktop používá tři informační bloky Profil / Kontakt / Projekt a mobilní layout se bezpečně skládá pod sebe.
- Přihlašovací obrazovka rozlišuje **Web** a **Web app/PWA** a obsahuje návod, jak Yamachat z otevřeného `yamachat.eu` nainstalovat přes nabídku aplikací podporovaného prohlížeče.
- Windows instalační návod vysvětluje, že současný build zatím nemá code-signing podpis a proto může prohlížeč nebo Microsoft Defender SmartScreen zobrazit upozornění na neznámou nebo málo používanou aplikaci.
- Release je postavený přímo na vydané 1.0.105 a zachovává současný **voice, stream, WebRTC, notifikace, updater, Friends/DM, servery, kanály a platformní rozložení**.
- Před publikováním musí projít společné Web/PWA, Android, iOS a Windows kontroly včetně voice/stream regresních testů.

Předchozí vydání v1.0.105 zůstává dostupné pro návrat.
