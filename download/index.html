iPhone / iPad

iOS verze je připravená pro první podepsaný build. Jakmile propojíme Apple Developer účet, budeme ji instalovat přes TestFlight.

Druhý krok

Android

Instalační APK pro telefon nebo tablet. Po vydání první mobilní verze se tlačítko automaticky propojí s nejnovějším APK v GitHub Releases.

APK zatím není vydané
Projekt Androidu je připravený. Veřejné APK ještě musí projít prvním buildem a podepsáním.
