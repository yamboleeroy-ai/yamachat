# Yamachat 1.0.105

- Právní a licenční baseline Yamachatu je nyní součástí projektu i distribučních balíčků pro Windows, Web/PWA, Android a iOS-derived buildy.
- Yamachat je výslovně označen jako proprietární projekt Lukáše Hubáčka. Historické ISC package metadata byla nahrazena hodnotou UNLICENSED.
- Přidány a baleny jsou dokumenty LICENSE, BRAND-NOTICE.md, PROVENANCE.md, THIRD_PARTY_NOTICES.md, LEGAL-BASELINE.md a ASSET-MANIFEST.md.
- Právní baseline je navázaná na podepsaný tag `legal-baseline-2026-09-27`, který GitHub ověřil jako platný SSH podpis.
- Vlastní funkční kód, vzhled, voice, stream, notifikace, updater, WNS identita a mobilní rozložení se tímto vydáním nemění.
- Legacy message notification sound zatím není zahrnut mezi proprietární Yamachat assety a bude nahrazen samostatně.

Předchozí vydání v1.0.104 zůstává dostupné pro návrat.
